# Sagnac Trading website

Next.js 15 (App Router) static export, Tailwind 3, `motion` for animation. Bilingual (zh default / en) copy lives in `lib/i18n/*.ts`.

## Commands
- `npm run typecheck` — TypeScript check
- `npm run build` — static export into `out/` (needs network: next/font fetches Google Fonts)
- `npx next dev -p <port> -H 127.0.0.1` — dev server
- Production: `server.cjs` serves `out/` with `serve` on port 3003 under pm2 (`ecosystem.config.cjs`, app `sagnac-trading`); nginx site `/etc/nginx/sites-available/sagnac.ai` (copy of `nginx-sagnac.conf`) proxies sagnac.ai and sagnac.trading (+ www) to it. Cloudflare proxies both domains and terminates TLS; the origin listens on port 80 only. sagnac.ai is canonical (`metadataBase`, per-page `alternates.canonical`). The old Janus site still runs separately on port 3002. Never use `serve -s` (SPA fallback rewrites /about to /).

## Notes
- Live record (homepage section and `/performance`): one file, `data/performance/live.json`, the combined net value of the live market-making accounts (Oculus books MM2, quandora, Bybit mm), ratios only. Oculus writes it: `cd ~/JanusOculus/backend && ~/miniconda3/bin/python -m oculus.ledger.composite site --out ~/sagnac-trading/out/data/performance/live.json --out ~/sagnac-trading/public/data/performance/live.json` (crontab, daily at 00:10 UTC; log `~/JanusOculus/logs/composite-site.log`). It goes to `out/` (what is served) and to `public/` (what the next `next build` copies into `out/`), so a rebuild keeps the current record. The page fetches it at runtime; shape in `lib/performance.ts`, method in the notes of `lib/i18n/performance.ts`. Never publish an amount, an account or an exchange name.
- Sagnac motifs in the UI, all from the firm's own picture (two beams round one loop, fringes that shift): the logo's lower fringes drift by one period on load and hover (`components/logo.tsx`, `.logo-fringes`); the hero's instrument is `components/ui/phase-strip.tsx` (the lower row follows the pointer and the scroll, read out as Δφ); `ScrollProgress` is two beams from the window's edges that meet in the middle at the end of the page; nav links underline from both ends (`.beam-link`); a strategy card is a loop with two counter-rotating lights while hovered (`.loop-card`); daily returns are drawn as fringes, gains above the line and losses below in the accent (`DailyFringes`); the net-value curve draws itself once in view. CSS in `app/globals.css` under "Sagnac motifs"; every one of them rests under `prefers-reduced-motion`.
- Story page `/about`: copy in `lib/i18n/about.ts` — prologue, four dated chapters (1913 / 1925 / 1963 / 2023), the name, three convictions (observation / latency in Rust / direction from mathematics and ML), coda. Every fact in the copy is sourced; keep it that way. Glyphs in `components/about/glyphs/` are SVG line art drawn via motion `pathLength`; dashed paths must use the `fade` variant, not `draw`.
- Reduced motion: keep server and client markup identical (hide via `motion-reduce:` CSS instead of returning null), otherwise React hydration error #418 in production.
- Visual verification: Playwright is available from the npx cache (`/home/ubuntu/.npm/_npx/e41f203b7505f1fb/node_modules/playwright`); scratch scripts and screenshots go in `.tmp/` (gitignored), e.g. `node .tmp/sagnac-shot.cjs http://127.0.0.1:3013 about zh 1440 900`.
- Brand: official logo SVGs live in `logo/` (source, with README) and are copied to `public/brand/`. `components/logo.tsx` inlines their paths (`variant` full / mark / wordmark) and fills them from the `--logo-*` CSS variables (cyan colorway, on-dark by default). `public/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` and `og.jpg` are rendered from those SVGs with `node .tmp/brand-assets.cjs`; Cloudflare caches static files for 4 h, so bump the `?v=` on their URLs in `app/layout.tsx` and the pages whenever these files change.
- Themes: only Dark (default) and Light (`lib/themes.ts`, nav toggle in `components/theme-toggle.tsx`). Both share the same root colours; every dark block carries the `ink-surface` class, and `html[data-theme="light"] .ink-surface` in `app/globals.css` flips it to light (white ground, dark text, blue accent, on-light logo). New dark blocks must get `ink-surface`, and buttons on them should hover with `hover:bg-paper/85`, not `hover:bg-white`. An inline script in `app/layout.tsx` sets `data-theme` before first paint (hence `suppressHydrationWarning` on `<html>`). The /about page uses only theme tokens, never fixed colours.
